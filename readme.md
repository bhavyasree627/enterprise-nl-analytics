# 📈 Enterprise Natural Language Analytics Engine

An enterprise-grade, secure, zero-cost Text-to-SQL data visualization and analytics platform built for production environments. This application translates natural language prompts into secure SQLite queries, validates them against AST-based security guardrails, executes live financial analytics, and dynamically renders Plotly visual charts.

---

##  Architectural Overview & Tech Stack

```
[ User Natural Language Prompt ]
              │
              ▼
    [ Google Gemini REST API ] ──(Generates SQL via Schema Context)
              │
              ▼
    [ AST Parser (sqlparse) ] ──(Security Guardrail: Enforces Read-Only SELECT)
              │
              ▼
    [ SQLite Database ] ────────(Executes Safe Query on Financial/Stock Data)
              │
              ▼
    [ Streamlit + Plotly ] ─────(Dynamic Tabular & Visual UI Rendering)
```

- **Frontend & UI:** Streamlit
- **Database & ETL:** SQLite + `yfinance` (Automated Market Data Pipeline)
- **Natural Language Engine:** Google Gemini REST API (`gemini-1.5-flash`) via `requests`
- **Security Guardrails:** Abstract Syntax Tree (AST) parsing via `sqlparse` to prevent SQL injection and unauthorized operations.
- **Configuration Management:** Environment variables managed securely via `python-dotenv`.

---

## 🛡️ Security & Compliance Standards

1. **Defense-in-Depth SQL Guardrails:** Before any SQL query generated by the LLM touches the database engine, it passes through an AST-level verifier (`security.py`). It explicitly strips comments, checks statement types, and rejects any mutating operations (`DROP`, `DELETE`, `INSERT`, `UPDATE`, `ALTER`).
2. **Credential Isolation:** API keys are injected via environment variables (`.env`) or secure environment scope, ensuring zero hardcoded secrets and full compliance with static application security testing (SAST) standards.

## ⚙️ Local Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/enterprise-nl-analytics.git
cd enterprise-nl-analytics
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Configure Environment Secrets
Create a `.env` file in the root directory of your project and add your Google Gemini API key:
```env
GEMINI_API_KEY=your_actual_google_gemini_api_key_here
```

### 4. Initialize Database & Run the Application
Execute the Streamlit server:
```bash
streamlit run app.py
```
